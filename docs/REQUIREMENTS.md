# photo-frame 需求与注意事项（汇总）

> 本文是**需求清单 + 禁忌速查**；技术根因与推导细节在 [`KEY-FINDINGS.md`](KEY-FINDINGS.md)，实现计划在 [`PLAN.md`](PLAN.md)。
> 改代码前先读本文的「禁忌」一节，能省掉大量重复排查。

---

## 一、功能需求（当前形态）

| # | 需求 | 验收标准 |
|---|---|---|
| F1 | 桌面常驻相框，显示本地图片/视频 | 托盘图标常驻；图片/视频都能显示 |
| F2 | 目录扫描 | 递归扫描配置的媒体目录，只认支持的扩展名；后台线程扫描不卡 UI |
| F3 | 自动轮换 | 可开关；间隔可调（秒）；可随机；被其它窗口遮挡时自动暂停（省 CPU） |
| F4 | PNG 相框 | 从内置相框库选；相框 PNG 叠在照片上，**照片只能出现在相框内孔里**，不许漏到框外/框外轮廓缺口 |
| F5 | 相框自适应（智能引擎） | 自动分析 PNG：区分外部/内部透明区 → 最大内接矩形 → 四角/四边 → **9-slice**；相框可横可竖、四角不变形、素材铺满内孔（不裁切）；`grow_percent` 默认 3% 只加粗边框 |
| F6 | 拖动移动相框 | 光标进入才显示控制层；拖动跟手不卡顿；松手才真正移动并保存 |
| F7 | 右下角缩放 | 拖右下角改上限尺寸，保持比例，松手保存 |
| F8 | 设置面板 | 点状态栏图标弹出；再点/ Esc / 点面板外 / 别的窗口获焦 → 收起；**每项改完立即生效并落盘** |
| F9 | 登录自启 | `~/.config/autostart/photo-frame.desktop`，登录后自动运行 |
| F10 | 视频 | ffmpeg 解码；自动播放/静音/帧率上限可调；播完整段再切下一项 |
| F11 | 清晰度 | 解码像素 **≥ 实际绘制像素**（永不上采样）；视频同；相框切片按**原始分辨率**保存、绘制时缩放 |
| F15 | 手机素材 | HEIC/HEIF 照片可用（外部解码器回退）；MOV 按容器旋转矩阵正确显示为竖屏 |
| F13 | 任意 PNG 自动可用 | 新相框 PNG 丢进 `frame/` 即可，无需改代码/配置；分析结果 `FrameModel` 可缓存（二次启动 0 次分析） |
| F14 | 视觉验收 | 每个核心改动后必须出**效果图**（`scripts/visual-test.sh` → `target/visual/`），检查变形/裁切/穿框/空隙/锯齿 |
| F12 | 崩溃自愈意识 | 每轮改动后自查 `coredumpctl`，有新的崩溃记录就必须查清并修 |

## 二、审美 / 交互要求

1. **控制层（播放/暂停、缩放箭头）只在鼠标悬停时出现，移出即消失**，不能常驻。
2. **设置页是"插件式弹出面板"**：无标题栏、圆角 popover 卡片、紧凑行高（约 26px）、右上角对齐顶栏、轻微模态压暗（0.06~0.10）、层叠在普通窗口之上但**不参与平铺、不抢平铺位**。
3. **照片要"长在相框里"**：铺满内孔最大范围，异形部分由遮罩精确裁掉；相框自身不透明、不能漏桌面/黑块；宁可裁切也不要照片溢出框外。
4. **尺寸关系要看得见**：相框比素材大一圈（默认 3%），形成"卡纸"感；换图时相框随素材自适应。
5. **界面自适应分辨率**：面板高度按可用区算，内容超高时内部滚动，不能把底部行裁掉够不到。
6. **不要突兀的常驻 UI、不要半透明残影、不要黑色底块**（layer surface 透明必须显式处理）。
7. 文案用中文、简洁、说人话（如"相框外扩 3%"、"点外面关闭"）。

## 三、开发流程要求

1. **先复现 + 取证据再改**：日志、截图、让程序自报坐标/状态；不要凭猜。
2. **定位根因**（"闪退"常常不是 Rust 崩了，而是被合成器踢掉；"点了没反应"常常是请求重绘的链路没接上）。
3. **最小修复**，不顺手改无关逻辑。
4. **全量回归**：改完设置页要把**每一项**点一遍并校验配置真的变化、副作用正常；改完交互要把**所有交互路径**走一遍。
5. **清理**：删掉本轮试错留下的探针/临时开关/死代码；保留有意的 `#[allow(dead_code)]` 时在注释里说明理由。
6. **提交**：一条提交只讲一件事；提交信息用 `git commit -F 文件`（避免 shell 吃掉反引号）；正文写清「症状 → 根因 → 修法 → 验证」。
7. **收尾**：装到实际运行路径、重启、恢复用户的工作区/工作表/配置，别把测试残留留给用户。
8. **不擅自**：不改用户的 hypr/omarchy 配置、不装系统包（要 sudo / 装包前先问）、不删用户的工作区。

## 四、禁忌速查（再犯就是白干）

| 现象 | 真因 | 规矩 |
|---|---|---|
| 相框的媒体从框外漏出/露边 | 遮罩 `DestOut` 没先 `translate` 到相框矩形；或把半透明羽化带当成内孔 | 遮罩擦除前必须平移；`ALPHA_CUT` 用 160 而不是几十 |
| 照片没按素材比例、上下露桌面 | 媒体矩形用内孔 bbox 而非"按素材比例的最大内接矩形 ∪ 包围盒" | 媒体绘制矩形 = `媒体比例的最大内接矩形 ∪ 内孔包围盒`（并集，覆盖不留缝） |
| 相框被拉到屏幕外、位置跳 | 把 `window.x/y` 当"素材左上角"再居中相框 | `x/y` 就是**相框左上角**，与拖动/停靠/输入区域语义一致 |
| 图片/视频发糊 | 解码尺寸乘了废弃的 `media_scale(0.96)` 等系数，比绘制小 → 合成器放大 | 解码像素 ≥ 绘制像素（宁多勿少），禁止再乘内缩系数 |
| 点"打开目录"闪退 | 把 layer-shell surface 当对话框 transient parent → 协议错误被合成器踢 | layer surface 不做 xdg_toplevel 父子关系；开对话框时先收起面板 |
| 面板里的下拉一点就消失 | 拿 `is_active_notify` 当"失焦"：GTK 弹窗会让 toplevel 的 is_active 变 false | 焦点判定只用 Hyprland `activewindow(v2)` 且按负载去重；别把 `workspace` 当失焦 |
| 点面板外不关闭 | 第二个"透明遮罩表面"收不到鼠标事件 | 面板窗口自己铺满可用区，用坐标判断点在卡片内/外；**不要**用四边锚定拉伸的独立 surface 当遮罩 |
| 按钮/播放条一直挂着不消失 | 自绘组件的"请求重绘"回调没注册，动画最后一帧刷不出来 | 自绘 + 动画的组件，必须把 `queue_draw` 注册进去 |
| 悬停显隐失灵 | 输入区域临时扩到整屏时，收不到 leave | 每次 motion 按指针**实际位置**判断（`hit()` 落框外返回 None） |
| 某个设置开关点了没反应 | `sanitize()` 里有派生赋值把用户写入覆盖掉 | 派生逻辑不要放在 `sanitize`；`enabled` 这类字段保持独立 |
| 改目录后内容不刷新 | 媒体源启动时创建一次就固定，`rescan` 扫的还是旧目录 | 改目录要 `set_source` + 重建源 + 重新扫描 |
| 选目录选成了文件 | 用了 `FileDialog::open()`（选文件） | 用 `select_folder()` |
| 日志里每 30 秒一次 DBus 签名错误 | 托盘 `ToolTip` 签名/字段写错 | SNI `ToolTip` 必须是 `(sa(iiay)ss)` 四字段 |
| 相框变大/变小时闪一下 | 缩放用了"媒体预览"而不是实时改上限盒 | 缩放直接改上限盒（`set_preview_box`），拖动中只改绘制 |
| 相框内露出一圈桌面（透明漏洞） | 九宫格中心片用了"安全内接矩形"（比内孔小） | 中心片 = **内孔范围**；安全矩形只用于诊断/兜底 |
| 换了个"透明"PNG 就崩溃 | 该 PNG 其实没有 alpha 通道，旧洪泛路径按 4 通道读越界 | 入口 `has_alpha()`/`n_channels()>=4` 挡住并退回叠图 |
| 相框四角被拉长变形 | 把整张 PNG 拉伸到素材比例 | 九宫格：四角同比缩放（`k` 相同），只有四边拉伸 |
| 相框上有一条"画出来的细线"（单条） | 切片 cairo 填充默认开抗锯齿，共享边被半透明化 → 发丝缝 | 填切片前 `set_antialias(None)` + 每片 0.5px overlap |
| 相框上有"十字/井字"细线（成组） | 开发调试网格被当渲染结果 | 见下一节；默认关闭 + 显式开关 + WARN |
| iPhone 照片（HEIC）不显示 | gdk-pixbuf 没有 heif loader | 解不了就调 ffmpeg/magick 转 PNG 再走原流程（不擅自抠白底） |
| iPhone 视频画面被压扁/比例错 | 只读 `width/height`，忽略容器旋转矩阵 | ffprobe 读 `rotation`，90/270 时交换宽高 + ffmpeg `-autorotate 1` |
| 相框比"最大宽高"设置还大 | 九宫格拉伸让外框突破上限盒 | `layout_adaptive` 带 `max_frame`：超标整体等比缩小（floor 防溢出） |
| MOV 一闪而过（共 0 帧） | 显式传 `-autorotate` 被该 ffmpeg 当输出选项 → ffmpeg 报错退出 | 别传 `-autorotate`（默认就开）；改 ffmpeg 参数后**手动跑一遍**看真实报错 |
| 相框上出现十字/井字细线 | 多半是开发调试网格（切片边框+内容区虚线） | 调试网格必须显式 `PHOTO_FRAME_DEBUG_OVERLAY=1`，开启时打 WARN；收尾不带调试变量重启 |

更完整的症状→根因对照见 `KEY-FINDINGS.md`（按章节号对照，如「三点八 设置面板」「三点九 控制层」「三十 layer-shell 里开对话框」）。

## 五、本机环境约束（不要改、不要装）

- 合成器：Hyprland（layer-shell 可用）；显示器：`HEADLESS-1`（scale_factor 报 2，物理 1.25×）+ HDMI 镜像
- 配置与日志：`~/.config/omarchy-photo-frame/config.toml`、`~/.local/state/omarchy-photo-frame/logs/`
- 相框库：`~/photo-frame/frame/*.png`（`frame/` 不进 git）
- 无 GStreamer 解码器；视频走系统 `ffmpeg`（与 `owe` 同一套）
- 需要装包/改系统配置 → **先问用户**

## 六、常用命令

```bash
cd ~/photo-frame
cargo build --release && cargo test          # 编译 + 22 个单测
make install                                  # 装到 ~/.local/bin + 自启项
pkill -x photo-frame; setsid nohup ~/.local/bin/photo-frame >/dev/null 2>&1 &   # 重启
PHOTO_FRAME_LOG=debug ~/.local/bin/photo-frame 2>&1 | tail -50   # 带调试日志跑
coredumpctl list photo-frame --no-pager | tail -3                # 崩溃自查
scripts/rollback.sh v1.0.0                                        # 一键回滚
```
